# Gym Tracker 💪

Gym Tracker es una WebApp moderna diseñada para registrar la asistencia y el progreso en el gimnasio siguiendo una rutina semanal preconfigurada.

## 🚀 Tecnologías Usadas
- **React (Vite)**
- **Tailwind CSS** para los estilos
- **Firebase** (Autenticación y Firestore)
- **Recharts** para gráficos de estadísticas
- **Lucide React** para la iconografía

## 📋 Características
- **Autenticación Segura**: Inicia sesión o regístrate usando correo electrónico y contraseña.
- **Rutina Semanal Inteligente**: El panel principal te muestra automáticamente la rutina que corresponde al día actual (Push, Pull, Legs, o Descanso).
- **Check-ins de Entrenamiento**: Permite registrar tu asistencia diaria y agregar notas sobre los ejercicios que realizaste.
- **Estadísticas**: Visualiza la constancia de asistencia y compárala gracias al panel de gráficos interactivos.

## 🛠️ Instalación y Uso Local

1. Instalar las dependencias del proyecto:
   ```bash
   npm install
   ```

2. Ejecutar el entorno de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre el navegador y visita el enlace que provee la terminal (normalmente `http://localhost:5173`).
